Pixel Diorama: a new Export tab saves the scene's loop in any style, not only pixel art, as an MP4 or an animated PNG. The loop is drawn one frame at a time, so it joins up when it repeats and no frame is dropped, and it uses the view as it is when you press the button: it doesn't rock, and turning or zooming while it runs changes nothing. Save this frame works in every style too. In full screen, an Export button beside the record button opens the same choices, so a loop can be exported at the view's biggest size.
